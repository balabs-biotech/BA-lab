01 / ENTRANCE REVEAL
ML–001Intersection Observer

Scroll reveal

Reveal an element only when it enters the viewport. Add a restrained delay for rhythm, not spectacle.

const io = new IntersectionObserver(([entry]) => {
  if (entry.isIntersecting) {
    entry.target.classList.add('is-visible');
    io.disconnect();
  }
});
io.observe(element);

02 / POINTER SPOTLIGHT
ML–002CSS variables

Local light

A soft radial light follows the pointer inside a surface. It adds depth without tilting or moving the content.

surface.addEventListener('pointermove', e => {
  const r = surface.getBoundingClientRect();
  surface.style.setProperty('--x', e.clientX-r.left+'px');
  surface.style.setProperty('--y', e.clientY-r.top+'px');
});
03 / MAGNETIC RESPONSE
ML–003Pointer interaction

Magnetic control

A small, bounded response gives a button a tactile quality. The hit area and keyboard behavior remain unchanged.

button.addEventListener('pointermove', e => {
  const r = button.getBoundingClientRect();
  const x = (e.clientX-r.left)/r.width-.5;
  const y = (e.clientY-r.top)/r.height-.5;
  button.style.transform = `translate(${x*5}px,${y*4}px)`;
});

Living filaments

A lightweight network of moving points and connections. A visual metaphor for relationships, not a fake scientific simulation.

OUR RULES

Motion with a reason.

Free does not mean careless. Each contribution should be useful, legible, lightweight and respectful of different devices.

01 / PERFORMANCE

Light by default

Prefer transform and opacity. Avoid permanent animation loops when the demo is off-screen. Respect data-saving preferences.

02 / ACCESSIBILITY

Motion is optional

Honor prefers-reduced-motion. Keep keyboard access, focus visibility and readable contrast. Never hide essential information behind animation.

03 / OPENNESS

Copy, adapt, share

Original BA Labs snippets are intended to be released under the MIT License, with attribution appreciated but not required. Third-party contributions must state their own license.

04 / INTENT

Every effect earns its place

Use motion to orient, reveal, connect or provide feedback. If it does none of these, remove it.
